# Busca de Pacientes

Projeto de estudo em JavaScript com foco em lógica de busca, manipulação de dados em objetos e interação com o DOM.

## 📌 Visão geral

Este projeto foi desenvolvido como um exercício de aprendizagem para praticar:

- estruturação de páginas com HTML
- estilização básica com CSS
- uso de JavaScript para manipular dados
- busca de informações em um array de objetos
- atualização dinâmica da interface com o DOM

O objetivo é permitir que o usuário informe o ID de um paciente e receba as informações correspondentes em tela, com feedback visual de sucesso ou erro.

## 🧩 Funcionalidades

- formulário para buscar paciente por ID
- validação de entrada do usuário
- pesquisa em um array de objetos
- retorno de dados do paciente encontrado
- mensagem de erro quando o paciente não existe
- estilização condicional para estados de sucesso e falha

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript vanilla

## 🚀 Como executar

1. Abra a pasta do projeto no seu editor.
2. Localize o arquivo `index.html`.
3. Abra-o no navegador ou use uma extensão como Live Server para visualização mais prática.
4. Digite um ID de paciente e clique em "Buscar".

## 🧠 Aprendizados aplicados

Este projeto reforça conceitos fundamentais de desenvolvimento web, como:

- criação de formulários em HTML
- uso de eventos do navegador com JavaScript
- acesso e atualização de elementos do DOM
- uso do método `find()` para localizar dados em arrays
- renderização dinâmica de conteúdo na página
- organização simples de código para projetos iniciais

## 🎯 Objetivo

Este projeto representa uma etapa de aprendizado no desenvolvimento front-end, demonstrando o entendimento de lógica de programação aplicada a interfaces web. Ele mostra a progressão de um iniciante em direção a projetos mais completos, com foco em praticidade, clareza e funcionalidade.
